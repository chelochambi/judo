# 📚 Glosario de Terminología Técnica de Judo

Este glosario reúne los términos en japonés utilizados en la nomenclatura oficial del **Gokyo No Waza** y del **Nage-no-Kata**. Cada término describe un elemento clave de la mecánica corporal, la dirección del desequilibrio (*kuzushi*), la zona anatómica empleada o la acción técnica específica ejecutada por *Tori*.

---

## 🥋 Diccionario de Términos

| Término | Traducción | Descripción / Contexto en Judo |
| :--- | :--- | :--- |
| **Ashi** | Pie / Pierna | Extremidades inferiores empleadas para barrer, bloquear o enganchar.[cite: 1] |
| **Barai (Harai)** | Barrido / Barrer | Movimiento fluido continuo para retirar la base de apoyo.[cite: 1] |
| **De** | Avanzar / Salir | Acción ejecutada sobre el pie que avanza o da un paso al frente.[cite: 1] |
| **Gaeshi (Kaeshi)** | Inversión / Contra / Voltear | Responder o invertir la técnica aplicada por el rival.[cite: 1] |
| **Gake (Kake)** | Enganche / Colgar | Enganchar o fijar el pie/tobillo del oponente a ras del suelo.[cite: 1] |
| **Gari (Kari)** | Sega / Segar | Acción de cortar o segar la pierna del rival (como con una hoz).[cite: 1] |
| **Goshi (Koshi)** | Cadera / Cintura | Apoyo o pivote principal usando la cadera.[cite: 1] |
| **Guruma** | Rueda | Movimiento de rotación continua del oponente alrededor de un eje.[cite: 1] |
| **Hane** | Resorte / Salto | Acción impulsiva y elástica de la pierna o cadera para catapultar.[cite: 1] |
| **Harai** | Barrer / Barrido | Acción de barrida continua.[cite: 1] |
| **Hiza** | Rodilla | Uso de la rodilla como punto de apoyo, bloqueo o pivote.[cite: 1] |
| **Ippon** | Un punto / Un solo lado | Ejecución directa concentrada en un solo agarre o brazo.[cite: 1] |
| **Kata** | Hombro | Articulación o zona del hombro empleada como palanca o punto de carga.[cite: 1] |
| **Ko** | Pequeño / Pequeña | Indica una trayectoria técnica o barrido más corto o fino.[cite: 1] |
| **Komi** | Entrar / Traer hacia adentro | Movimiento de aproximación pegando el cuerpo del rival al propio.[cite: 1] |
| **Kukyu (Kyu)** | Vacío / Aire | Proyección aprovechando la ausencia de apoyo o la dirección del aire.[cite: 1] |
| **Makikomi** | Envolver / Enrollar | Caer enrollando el cuerpo propio junto con el del oponente.[cite: 1] |
| **Morote** | Ambas manos / Dos manos | Uso coordinado de ambas manos agarrando directamente al rival.[cite: 1] |
| **Nage** | Proyección / Lanzamiento | Término general para derribos o lanzamientos.[cite: 1] |
| **O** | Gran / Grande | Indica una amplitud mayor en la acción de la técnica o del barrido.[cite: 1] |
| **Okuri** | Enviar / Acompañar | Desplazamiento coordinado acompañando el movimiento del rival.[cite: 1] |
| **Otoshi** | Caída / Descenso | Proyección mediante una fuerza o movimiento descendente directo.[cite: 1] |
| **Sasae** | Bloqueo / Sostener | Obstáculo o freno colocado en el pie/tobillo del oponente.[cite: 1] |
| **Seoi** | Cargar en la espalda | Cargar al oponente sobre el dorso o la espalda como base.[cite: 1] |
| **Soto** | Exterior / Afuera | Acción técnica realizada por la parte externa del cuerpo del rival.[cite: 1] |
| **Sumi** | Rincón / Esquina | Ángulo o dirección diagonal posterior/anterior del desequilibrio.[cite: 1] |
| **Tai** | Cuerpo | Uso del peso y posición del cuerpo para provocar la caída.[cite: 1] |
| **Tani** | Valle | Caída deslizándose por el espacio bajo (el "valle") detrás del rival.[cite: 1] |
| **Te** | Mano / Brazo | Extremidades superiores.[cite: 1] |
| **Tomoe** | Círculo / Forma de coma | Movimiento circular o en espiral similar al símbolo tradicional *Tomoe*.[cite: 1] |
| **Tsubame** | Golondrina | Movimiento rápido y veloz, característico del vuelo de la golondrina.[cite: 1] |
| **Tsuri** | Pescar / Elevar / Levantar | Tracción ascendente realizada con la mano de la solapa.[cite: 1] |
| **Tsurikomi** | Tirar y levantar | Acción combinada de elevación y tracción para romper el equilibrio.[cite: 1] |
| **Uchi** | Interior / Dentro | Acción ejecutada por la parte interna del cuerpo del oponente.[cite: 1] |
| **Uki** | Flotante / Flotar | Desequilibrio o movimiento en el aire sin punto de apoyo firme.[cite: 1] |
| **Ura** | Atrás / Opuesto / Espalda | Proyección o movimiento dirigido hacia la espalda.[cite: 1] |
| **Waza** | Técnica / Arte / Habilidad | Categoría o clasificación técnica.[cite: 1] |
| **Yoko** | Lado / Lateral | Acción o caída ejecutada sobre un plano lateral.[cite: 1] |
