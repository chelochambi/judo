# 📚 Glosario General de Terminología Técnica de Judo

Este glosario reúne y estandariza las raíces y términos fundamentales en japonés utilizados en la nomenclatura oficial del **Gokyo No Waza** (grados Kyu), del **Nage-no-Kata** y del **Katame-no-Kata** (grados Dan / Shodan), así como los conceptos de ejecución técnica y metodología en el tatami.

Al descomponer los términos compuestos en sus raíces individuales (por ejemplo, *Kumi* + *Kata*, *Tai* + *Sabaki*, *Hiki* + *Dashi*), resulta más sencillo comprender la anatomía, la dirección y la mecánica de cualquier técnica o movimiento.

## 🥋 Diccionario de Raíces y Términos (Orden Alfabético)

| Término | Traducción | Descripción / Contexto en Judo | 
| ----- | ----- | ----- | 
| **Ashi** | Pie / Pierna | Extremidades inferiores empleadas para barrer, bloquear, enganchar, apoyar (*Jiku-ashi*) o desplazarse (*Tsugi-ashi*). | 
| **Barai (Harai)** | Barrido / Barrer | Movimiento fluido continuo para retirar la base de apoyo del oponente. | 
| **Dashi** | Sacar / Extraer / Avanzar | Acción de proyectar hacia afuera o extraer el equilibrio (*Hiki-dashi*). | 
| **De** | Avanzar / Salir | Acción ejecutada sobre el pie que avanza o da un paso al frente. | 
| **Eri** | Solapa / Cuello | Agarre del cuello del *judogi* empleado en controles y estrangulaciones. | 
| **Finta** | Amago / Engaño | Movimiento previo o ataque falso para provocar una reacción que abra espacios. | 
| **Gaeshi (Kaeshi)** | Inversión / Contra / Voltear | Responder o invertir la técnica aplicada por el rival (*Kaeshi-waza*). | 
| **Gake** | Enganche / Colgar | Enganchar o fijar el pie/tobillo del oponente a ras del suelo. | 
| **Garami** | Entrelazado / Envolver | Control articulado o cruzado envolviendo las extremidades. | 
| **Gari (Kari)** | Sega / Segar | Acción de cortar o segar la pierna del rival (como con una hoz). | 
| **Gatame (Katame)** | Control / Inmovilización / Fijación | Mantener bajo control el cuerpo o la articulación del rival. | 
| **Goe** | Voz / Impulso / Señal | Grito, señal o impulso inicial para coordinar un movimiento o provocar una reacción (*Kake-goe*). | 
| **Goshi (Koshi)** | Cadera / Cintura | Apoyo, carga o pivote principal usando la cadera. | 
| **Guruma** | Rueda | Movimiento de rotación continua del oponente alrededor de un eje. | 
| **Gyaku** | Inverso / Opuesto | Ejecución en sentido o dirección contraria a la norma básica. | 
| **Hadaka** | Desnudo / Directo | Control o estrangulación ejecutado directamente sin usar la solapa del *judogi*. | 
| **Handō** | Reacción / Rebote | Fuerza o impulso en sentido contrario generado por el oponente al resistir o empujar (*Handō-no-kuzushi*). | 
| **Hane** | Resorte / Salto | Acción impulsiva y elástica de la pierna o cadera para catapultar. | 
| **Happo** | Ocho direcciones | Los 8 puntos cardinales y diagonales hacia donde se dirige el desequilibrio (*Happo-no-kuzushi*). | 
| **Hara** | Abdomen / Vientre | Zona abdominal utilizada como punto de apoyo en luxaciones y controles. | 
| **Harai** | Barrer / Barrido | Acción de barrida continua. | 
| **Hidari** | Izquierda / Lado izquierdo | Indica la guardia, postura (*Hidari-shizentai*), agarre o dirección de ataque hacia el lado izquierdo. | 
| **Hiki** | Tirar / Tracción | Acción de jalar o atraer hacia uno mismo (*Hiki-dashi*, *Hikite*). | 
| **Hishigi** | Hiperflexión / Aplastar | Romper o presionar la articulación más allá de su rango natural. | 
| **Hiza** | Rodilla | Uso de la rodilla como punto de apoyo, bloqueo o pivote. | 
| **Iko** | Transición / Paso | Cambio fluido de una fase o ámbito de trabajo a otro, como el paso de pie a suelo (*Ne-waza-iko*). | 
| **Ippon** | Un punto / Un solo lado | Puntuación máxima o ejecución directa concentrada en un solo agarre o brazo. | 
| **Jigo** | Autodefensa / Defensivo | Actitud o base corporal baja y firme para resistir ataques (*Jigotai*). | 
| **Jiku** | Eje / Pivote | Punto o pierna de apoyo firme alrededor de la cual gira el cuerpo (*Jiku-ashi*). | 
| **Jime (Shime)** | Estrangulación / Presión | Presión ejercida sobre las arterias carótidas o la tráquea. | 
| **Judogi** | Uniforme de judo | Traje tradicional compuesto por chaqueta (*uwagi*), pantalón (*zubon*) y cinturón (*obi*). | 
| **Juji** | Cruz / Cruzado | Posición cruzada de los brazos o piernas en el ataque. | 
| **Kaeshi (Gaeshi)** | Contraataque / Inversión | Respuesta técnica ejecutada invirtiendo o aprovechando el ataque fallido de *Uke* (*Kaeshi-waza*). | 
| **Kaiten** | Rotación / Giro | Movimiento giratorio o arco de vuelo que se imprime a *Uke* hacia el tatami. | 
| **Kake** | Ejecución / Proyección / Aplicar | Fase culminante de la proyección donde se aplica el impulso final para lanzar a *Uke* al tatami (también significa enganche/colgar como *Gake*). | 
| **Kami** | Arriba / Superior | Posición de control desde la zona de la cabeza del oponente. | 
| **Kansetsu** | Articulación / Luxación | Técnicas enfocadas en la articulación del codo (*Kansetsu-waza*). | 
| **Kari (Gari)** | Sega / Segar | Variante fonética de *Gari*; acción de segar la pierna de apoyo del rival. | 
| **Kata** | Hombro / Forma / Modo | Articulación del hombro, ejecución lateral o forma establecida de hacer algo (*Kumi-kata*). | 
| **Katame (Gatame)** | Control / Fijación / Sujeción | Variante fonética de *Gatame*; conjunto de técnicas de control e inmovilización. | 
| **Kesa** | Bufanda / Solapa cruzada | Control en diagonal cruzando el pecho del rival como un manto. | 
| **Kime** | Enfoque / Impulso explosivo | Aplicación precisa y enérgica de la fuerza en el instante culminante de la técnica (*Hikite-no-kime*). | 
| **Ko** | Pequeño / Pequeña | Indica una trayectoria técnica o barrido más corto o fino. | 
| **Kodokan** | Instituto del camino | Escuela y sede mundial del judo fundada por Jigoro Kano en 1882. | 
| **Komi** | Entrar / Traer hacia adentro | Movimiento de aproximación pegando el cuerpo del rival al propio (*Uchi-komi*, *Nage-komi*, *Osae-komi*). | 
| **Koshi (Goshi)** | Cadera / Cintura | Variante fonética de *Goshi*; apoyo, carga o contacto biomecánico con la cadera. | 
| **Kukyu (Kyu)** | Vacío / Aire | Proyección aprovechando la ausencia de apoyo o la dirección del aire. | 
| **Kumi** | Agarre / Enlace / Unión | Toma de contacto y sujeción sobre el *judogi* del oponente (*Kumi-kata*). | 
| **Kuzure** | Variante / Modificación | Inmovilización o técnica modificada de su forma fundamental. | 
| **Kuzushi** | Desequilibrio | Rompimiento de la postura y estabilidad de *Uke* antes de ejecutar la técnica. | 
| **Ma-ai** | Distancia / Intervalo | Espacio o distancia táctica entre *Tori* y *Uke* para atacar o defender con eficacia. | 
| **Makikomi** | Envolver / Enrollar | Caer enrollando el cuerpo propio junto con el del oponente. | 
| **Mawari** | Circular / Girar | Movimiento pivotante o rotatorio alrededor de un eje (*Mawari-sabaki*). | 
| **Migi** | Derecha / Lado derecho | Indica la guardia, postura (*Migi-shizentai*), agarre o dirección de ataque hacia el lado derecho. | 
| **Mitchaku** | Contacto estrecho / Adherencia | Cercanía corporal sin espacios muertos entre *Tori* y *Uke* para transmitir la fuerza. | 
| **Morote** | Ambas manos / Dos manos | Uso coordinado de ambas manos agarrando directamente al rival. | 
| **Nage** | Proyección / Lanzamiento | Término general para derribos o lanzamientos (*Nage-waza*, *Nage-komi*). | 
| **Nami** | Normal / Ordinario | Disposición estándar de los agarres en cruz (palmas hacia abajo). | 
| **Ne** | Suelo / Mat | Trabajo técnico realizado en el suelo (*Ne-waza*, *Ne-waza-iko*). | 
| **O** | Gran / Grande | Indica una amplitud mayor en la acción de la técnica o del barrido. | 
| **Okuri** | Enviar / Acompañar | Desplazamiento coordinado o deslizamiento continuo. | 
| **Osae (Osaekomi)** | Presionar / Inmovilizar | Mantener al oponente presionado de espaldas contra el tatami (*Osae-komi-waza*). | 
| **Otoshi** | Caída / Descenso | Proyección mediante una fuerza o movimiento descendente directo. | 
| **Renraku** | Encadenamiento / Conexión | Enlace fluido de una técnica con otra cuando la primera es bloqueada (*Renraku-waza*). | 
| **Ryote** | Ambas manos | Agarre con ambas manos en el mismo objetivo. | 
| **Sabaki** | Manejo / Control / Esquiva | Gestión fluida del movimiento o desplazamiento corporal (*Tai-sabaki*, *Mawari-sabaki*). | 
| **Sankaku** | Triángulo | Figura geométrica formada con las piernas para estrangular o luxar. | 
| **Sasae** | Bloqueo / Sostener | Obstáculo o freno colocado en el pie/tobillo del oponente. | 
| **Sente** | Iniciativa | Toma de la delantera táctica o aseguramiento previo del agarre y ritmo del combate. | 
| **Seoi** | Cargar en la espalda | Cargar al oponente sobre el dorso o la espalda como base. | 
| **Shiho** | Cuatro esquinas / Cuatro puntos | Control sujetando los cuatro puntos de apoyo del rival. | 
| **Shime (Jime)** | Estrangulación / Presión | Variante fonética de *Jime*; presión ejercida sobre el cuello o carótidas (*Shime-waza*). | 
| **Shisei** | Postura corporal | Colocación general del cuerpo y distribución del peso durante el combate. | 
| **Shita** | Abajo / Debajo / Inferior | Indica posición inferior, debajo del oponente o dirección descendente (*Shita-garami*, trabajo desde abajo en *Ne-waza*). | 
| **Shizen** | Natural / Espontáneo | Posición erguida, equilibrada y relajada que facilita moverse en cualquier dirección (*Shizentai*). | 
| **Sode** | Manga | Agarre realizado en las mangas de la chaqueta del *judogi*. | 
| **Soto** | Exterior / Afuera | Acción técnica realizada por la parte externa del cuerpo del rival. | 
| **Sumi** | Rincón / Esquina | Ángulo o dirección diagonal posterior/anterior del desequilibrio. | 
| **Tai** | Cuerpo / Postura | Uso del peso y posición del cuerpo (*Tai-sabaki*, *Shizentai*, *Jigotai*). | 
| **Tani** | Valle | Caída deslizándose por el espacio bajo (el "valle") detrás del rival. | 
| **Tatami** | Colchoneta / Esterilla | Superficie acolchada donde se practica y compite en judo. | 
| **Tate** | Longitudinal / A caballo | Control de suelo en posición vertical sobre el torso del oponente. | 
| **Te** | Mano / Brazo | Extremidades superiores (*Hikite*, *Tsurite*, *Te-waza*). | 
| **Tomoe** | Círculo / Forma de coma | Movimiento circular o en espiral similar al símbolo tradicional *Tomoe*. | 
| **Tori** | Quien ejecuta la técnica | Judoka que realiza la acción técnica o proyección sobre el compañero/oponente. | 
| **Tsubame** | Golondrina | Movimiento rápido y veloz, característico del vuelo de la golondrina. | 
| **Tsugi** | Siguiente / Seguido | Desplazamiento deslizante donde un pie sigue al otro sin cruzarse (*Tsugi-ashi*). | 
| **Tsukuri** | Colocación / Preparación | Acomodo corporal y biomecánico de *Tori* para cargar o proyectar tras iniciar el desequilibrio. | 
| **Tsuri** | Pescar / Elevar / Levantar | Tracción ascendente realizada con la mano de la solapa (*Tsurite*, *Tsurikomi*). | 
| **Uchi** | Interior / Dentro | Acción ejecutada por la parte interna del cuerpo del oponente (*Uchi-komi*). | 
| **Ude** | Brazo / Antebrazo | Extremidad superior objetivo de controles o luxaciones. | 
| **Ue** | Arriba / Encima / Superior | Indica posición superior o encima del oponente en *Ne-waza* (complementario a *Kami*). | 
| **Uke** | Quien recibe la técnica | Judoka sobre el que se aplica la técnica o proyección. | 
| **Uki** | Flotante / Flotar | Desequilibrio o movimiento en el aire sin punto de apoyo firme. | 
| **Ura** | Atrás / Opuesto / Espalda | Proyección o movimiento dirigido hacia la espalda. | 
| **Waki** | Axila / Costado | Zona lateral debajo del hombro utilizada como punto de apoyo. | 
| **Waza** | Técnica / Arte / Habilidad | Categoría o clasificación técnica (*Nage-waza*, *Ne-waza*, *Renraku-waza*, *Kaeshi-waza*). | 
| **Yoko** | Lado / Lateral | Acción o caída ejecutada sobre un plano lateral. | 
| **Zanshin** | Atención / Alerta posterior | Estado de concentración, equilibrio y control corporal mantenido después de ejecutar una técnica. |
