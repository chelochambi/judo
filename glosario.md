# 📚 Glosario General de Terminología Técnica de Judo

Este glosario reúne y estandariza la terminología en japonés utilizada en la nomenclatura oficial de las técnicas del **Gokyo No Waza** (grados Kyu), del **Nage-no-Kata** y del **Katame-no-Kata** (grados Dan / Shodan). 

Cada término describe la mecánica corporal, la dirección del desequilibrio (*kuzushi*), la zona anatómica implicada o la acción técnica específica ejecutada por *Tori*.

---

## 🥋 Diccionario de Términos (Kyu & Dan)

| Término | Traducción | Descripción / Contexto en Judo |
| :--- | :--- | :--- |
| **Ashi** | Pie / Pierna | Extremidades inferiores empleadas para barrer, bloquear, enganchar o controlar. |
| **Barai (Harai)** | Barrido / Barrer | Movimiento fluido continuo para retirar la base de apoyo. |
| **De** | Avanzar / Salir | Acción ejecutada sobre el pie que avanza o da un paso al frente. |
| **Eri** | Solapa / Cuello | Agarre del cuello del *judogi* empleado en estrangulaciones. |
| **Gaeshi (Kaeshi)** | Inversión / Contra / Voltear | Responder o invertir la técnica aplicada por el rival. |
| **Gake (Kake)** | Enganche / Colgar | Enganchar o fijar el pie/tobillo del oponente a ras del suelo. |
| **Garami** | Entrelazado / Envolver | Control articulado o cruzado envolviendo las extremidades. |
| **Gari (Kari)** | Sega / Segar | Acción de cortar o segar la pierna del rival (como con una hoz). |
| **Gatame (Katame)** | Control / Inmovilización / Fijación | Mantener bajo control el cuerpo o la articulación del rival. |
| **Goshi (Koshi)** | Cadera / Cintura | Apoyo o pivote principal usando la cadera. |
| **Guruma** | Rueda | Movimiento de rotación continua del oponente alrededor de un eje. |
| **Gyaku** | Inverso / Opuesto | Ejecución en sentido o dirección contraria a la norma básica. |
| **Hadaka** | Desnudo / Directo | Control o estrangulación ejecutado directamente sin usar la solapa del *judogi*. |
| **Hane** | Resorte / Salto | Acción impulsiva y elástica de la pierna o cadera para catapultar. |
| **Hara** | Abdomen / Vientre | Zona abdominal utilizada como punto de apoyo en luxaciones. |
| **Harai** | Barrer / Barrido | Acción de barrida continua. |
| **Hishigi** | Hiperflexión / Aplastar | Romper o presionar la articulación más allá de su rango natural. |
| **Hiza** | Rodilla | Uso de la rodilla como punto de apoyo, bloqueo o pivote. |
| **Ippon** | Un punto / Un solo lado | Ejecución directa concentrada en un solo agarre o brazo. |
| **Jime (Shime)** | Estrangulación / Presión | Presión ejercida sobre las arterias carótidas o la tráquea. |
| **Juji** | Cruz / Cruzado | Posición cruzada de los brazos o piernas en el ataque. |
| **Kami** | Arriba / Superior | Posición de control desde la zona de la cabeza del oponente. |
| **Kansetsu** | Articulación / Luxación | Técnicas enfocadas en la articulación del codo. |
| **Kata** | Hombro / Forma / Forma de lado | Articulación del hombro empleada como palanca, o ejecución lateral. |
| **Kesa** | Bufanda / Solapa cruzada | Control en diagonal cruzando el pecho del rival como un manto. |
| **Ko** | Pequeño / Pequeña | Indica una trayectoria técnica o barrido más corto o fino. |
| **Komi** | Entrar / Traer hacia adentro | Movimiento de aproximación pegando el cuerpo del rival al propio. |
| **Kukyu (Kyu)** | Vacío / Aire | Proyección aprovechando la ausencia de apoyo o la dirección del aire. |
| **Kuzure** | Variante / Modificación | Inmovilización o técnica modificada de su forma fundamental. |
| **Makikomi** | Envolver / Enrollar | Caer enrollando el cuerpo propio junto con el del oponente. |
| **Morote** | Ambas manos / Dos manos | Uso coordinado de ambas manos agarrando directamente al rival. |
| **Nami** | Normal / Ordinario | Disposición estándar de los agarres en cruz (palmas hacia abajo). |
| **Nage** | Proyección / Lanzamiento | Término general para derribos o lanzamientos. |
| **Ne** | Suelo / Mat | Trabajo técnico realizado en el suelo (*Ne-waza*). |
| **O** | Gran / Grande | Indica una amplitud mayor en la acción de la técnica o del barrido. |
| **Okuri** | Enviar / Acompañar | Desplazamiento coordinado o deslizamiento continuo. |
| **Osaekomi** | Inmovilización | Mantener al oponente de espaldas contra el tatami. |
| **Otoshi** | Caída / Descenso | Proyección mediante una fuerza o movimiento descendente directo. |
| **Ryote** | Ambas manos | Agarre con ambas manos en el mismo objetivo. |
| **Sankaku** | Triángulo | Figura geométrica formada con las piernas para estrangular o luxar. |
| **Sasae** | Bloqueo / Sostener | Obstáculo o freno colocado en el pie/tobillo del oponente. |
| **Seoi** | Cargar en la espalda | Cargar al oponente sobre el dorso o la espalda como base. |
| **Shiho** | Cuatro esquinas / Cuatro puntos | Control sujetando los cuatro puntos de apoyo del rival. |
| **Sode** | Manga | Agarre realizado en las mangas de la chaqueta del *judogi*. |
| **Soto** | Exterior / Afuera | Acción técnica realizada por la parte externa del cuerpo del rival. |
| **Sumi** | Rincón / Esquina | Ángulo o dirección diagonal posterior/anterior del desequilibrio. |
| **Tai** | Cuerpo | Uso del peso y posición del cuerpo para provocar la caída. |
| **Tani** | Valle | Caída deslizándose por el espacio bajo (el "valle") detrás del rival. |
| **Tate** | Longitudinal / A caballo | Control de suelo en posición vertical sobre el torso del oponente. |
| **Te** | Mano / Brazo | Extremidades superiores. |
| **Tomoe** | Círculo / Forma de coma | Movimiento circular o en espiral similar al símbolo tradicional *Tomoe*. |
| **Tsubame** | Golondrina | Movimiento rápido y veloz, característico del vuelo de la golondrina. |
| **Tsuri** | Pescar / Elevar / Levantar | Tracción ascendente realizada con la mano de la solapa. |
| **Tsurikomi** | Tirar y levantar | Acción combinada de elevación y tracción para romper el equilibrio. |
| **Uchi** | Interior / Dentro | Acción ejecutada por la parte interna del cuerpo del oponente. |
| **Ude** | Brazo / Antebrazo | Extremidad superior objetivo de controles o luxaciones. |
| **Uki** | Flotante / Flotar | Desequilibrio o movimiento en el aire sin punto de apoyo firme. |
| **Ura** | Atrás / Opuesto / Espalda | Proyección o movimiento dirigido hacia la espalda. |
| **Waki** | Axila / Costado | Zona lateral debajo del hombro utilizada como punto de apoyo. |
| **Waza** | Técnica / Arte / Habilidad | Categoría o clasificación técnica. |
| **Yoko** | Lado / Lateral | Acción o caída ejecutada sobre un plano lateral. |
